# 2026-08-12

## File editor feature added

Added in-place text editing to the BQ file manager, using the same write logic as BQMobileGestaltModel.

### Changes
- **BQFileSystem.swift**: Added `writeInPlace(at:data:)` method + `writeAll(fd:data:)` helper. Ported from BQMobileGestaltModel.write() — uses fd overwrite (O_WRONLY | O_CLOEXEC | O_NOFOLLOW), truncate/write/fsync on same inode, rollback on failure, post-write verification. Added `import Darwin` for POSIX calls.
- **BQDirectoryView.swift**: Added `EditableType` enum (plainText, plist(format), json), `EditableLoader` (loadEditable/serialize), and modified `BQFilePreview` to support inline edit mode with TextEditor, Save/Cancel toolbar, discard-changes alert, format badge overlay, and truncation guard. Plist format preserved on save (binary stays binary, XML stays XML).

## MobileHouseArrest sandbox escape PoC integrated

Added the user-provided PoC code for container escape via `container_object_sandbox_extension_activate`. The PoC only appears in the UI when the app's bundle ID equals `com.apple.mobile.MobileHouseArrest`.

### Changes
- **bad_query.h**: Added `bq_poc_result` struct (success, activated, denied_before, denied_after, restored, writable, message[512], path[1024]) and declared `bq_run_mha_poc()` / `bq_run_mg_class13_poc()`.
- **bad_query.c**: Converted both ObjC PoC functions to pure C. Added includes (fcntl.h, unistd.h, stdarg.h), new typedefs (container_object_copy_fn, container_object_free_fn, container_object_get_path_fn, container_object_activate_fn), helper functions (can_open, can_open_rw, read_file, write_file_simple, normalize_path, poc_set_message). MHA PoC: class-2 app-data container query for SandboxCanaryVictim, canary write/verify/restore. MG class-13 PoC: system-group container query for mobilegestaltcache, path verification, RW access check to MobileGestalt.plist. Uses `container_query_set_identifiers` (class 2) vs `container_query_set_group_identifiers` (class 13) — different from existing `bad_query()` which only uses the group variant.
- **BQSandboxPoCView.swift** (new): BQPocResult Swift wrapper, BQSandboxPoCModel (@Observable), BQSandboxPoCView with identity section, two PoC buttons, and detailed result cards.
- **BQRootView.swift**: Conditional "Research" section with NavigationLink to BQSandboxPoCView, only shown when `Bundle.main.bundleIdentifier == "com.apple.mobile.MobileHouseArrest"`.
- Project uses PBXFileSystemSynchronizedRootGroup (Xcode 16+), so new Swift file is automatically included in build.
